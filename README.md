# Мини-калькулятор

**Автор:** Ярослав  
**Тип проекта:** учебный мини-проект

## Описание
Простой калькулятор, работающий в браузере. Поддерживает сложение, вычитание, умножение, деление, очистку поля и удаление последнего символа. Выражения можно вводить кнопками или с клавиатуры.

## Технологии
- HTML5 — структура интерфейса;
- CSS3 — оформление и адаптивность;
- JavaScript — обработка действий и вычисления.

## Запуск
Откройте файл `index.html` в браузере. Дополнительная установка не требуется.

## Возможности
- Арифметические операции;
- вычисление по кнопке `=` или клавише Enter;
- очистка кнопкой `C` или клавишей Escape;
- удаление последнего символа кнопкой `⌫` или Backspace.
